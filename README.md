# StudyOCR v1.2.0

StudyOCR 是一款面向错题、笔记和纸质讲义整理的 Windows 离线 OCR 桌面软件。可将单张或多张照片转成可编辑的 Word 或可搜索的 PDF，并在原图旁校对文字、公式、表格和图注。

## 下载与快速上手

1. 下载 [Windows x64 免安装包](https://github.com/Adahuaimeng/studyOCR-/releases/download/v1.2.0/StudyOCR-1.2.0-win-x64.zip)，完整解压并双击 `StudyOCR.exe`。程序、运行库和 OCR 模型都在解压目录中。
2. 点击 **导入图片**，选择 **识别整图**，或在左侧拖出选区后选择 **识别选区**。也可以从 **文件** 菜单使用 USB 摄像头或同一局域网内的手机拍照。
3. 在右侧 **原图校对** 中纠正文字，按需选择印刷体、手写体或全部。双击表格可逐格校对，公式和图表可按需要保留为可编辑对象或原图小截图。
4. 选择 **Word 预览** 或 **PDF 预览** 检查版式后导出。多张图片可一次合并，可以自选页面并调整次序。需要继续校对时请保存 `.ocrproj` 工作稿。

## 主要功能

- **三种常用排版**：贴近原图、A4 讲义和照片 PDF。白底 PDF 支持可搜索文字；A4 讲义可加封面、目录和页码。
- **公式和图表**：已确认公式可以在 Word 中编辑，表格可以逐格调节，单元格可保留原图截图。图注可手动关联，导出可记录裁切在原图中的位置。
- **预览与编辑**：可边看原图边编辑 Word 或 PDF，也可单独打开编辑窗口。实际 Word 排版预览及 Word 同版 PDF 需要 LibreOffice。
- **离线 OCR 与 Agent 接口**：本地识别可直接运行，联网 AI 辅助默认关闭。外部 Agent 可以调用 `ocr-cli.exe` 读取结构化结果、提交校对和导出文档。 [Agent 调用说明](外部AI调用说明.md)
- **批处理与复核**：支持自动方向、批量恢复、低置信文字和公式表格分项复核。识别和格式还原会随图片清晰度与排版复杂度变化，复杂手写公式和图表建议导出前预览。

实拍测试图片和此版本生成的 Word 文件见 [测试样例](examples/README.md)。本页和下载说明对应 v1.2.0。

## 从源码运行

安装依赖后可双击 `启动.bat`。首次准备环境时，请安装带 Tkinter 的 64 位 Python 3.13，再在本目录用 PowerShell 执行以下命令。

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

首次使用对应的识别模式时可能下载模型。缓存完成后，识别在电脑本地运行。生成带中文文字层的 PDF 需要 Windows 中文字体。

### 离线安装

安装带 Tkinter 的 Windows 64 位 Python 3.13 后，将项目和 **离线依赖** 文件夹放在同一目录。在该目录运行 `py -3.13 offline.py install`，然后双击 `启动.bat`。安装只读取本地 wheel 文件，并将印刷识别和手写增强所需的模型放入新环境。

需要重新准备离线依赖时，在联网电脑上先安装 `requirements.txt`，再运行 `py -3.13 offline.py prepare`。若需要 Word 排版预览，也请在目标电脑提前安装 LibreOffice。自动检测支持 Windows 注册的安装路径，便携安装可通过 `OCR_SOFFICE` 指定 `soffice.com` 的路径。

## 工作区与快捷栏

- 点 **展开工具** 可在左侧显示识别选项和原图工具，处理完可点 **收起工具**。也可从 **视图 → 识别与导出选项** 调整识别模式、提取范围、PDF 样式和缩放。
- 在 **视图 → 自定义快捷栏** 选择、排序或还原按钮。快捷栏最多两排，放不下的按钮进入 **更多**。取消固定的功能仍可从菜单调用。快捷栏配置会保留到下次启动。
- **错题集**紧挨右侧的 **识别结果**。点该标签查看和整理选题，切回识别结果、预览或编辑时，错题集会让出内容区域。

## 图片与校对

1. 点 **导入图片**，可一次选多张。左侧用 **上一张／下一张** 或页码下拉框切换。横拍卷面可用 **左转 90°** 或 **右转 90°**。顶部的 **文件、编辑、视图、帮助** 菜单也提供相应入口。
2. 导入后点预览上方的 **框选区域**，或直接在左侧照片上按住鼠标左键拖动。出现蓝框后，**识别选区**和**另存截图**会亮起。拖出新框可替换旧选区。
3. 同页有印刷和手写时用 **混排识别**。可以识别整图，也可以拖框后识别选区。**通用识别**保留 OCR 原行，**手写增强**适合以手写为主的图片。
4. 在 **原图校对** 中选文字块，原图会标出位置。双击可改文字和类别，也可以批量改类别。对夹杂在同一块的内容可用 **拆分文字块**，对漏掉或压住印刷体的手写可拖框 **框选补录**。误识块可标为 **不导出**。
5. **另存截图**按原始像素保存 PNG。勾选 **自动保留图表** 后，预览中的青色虚线显示识别到的图表。漏掉时可以拖框后点 **保留原图区域**，Word 和白底 PDF 都会嵌入该截图。带格的表可点 **表格或公式**，核对单元格后导出 Word 表格。也可在这里录入确认过的 Word 原生公式，支持分式、根号和上下标。

桌面端整图识别会检查内容方向，选区识别沿用当前预览方向。遇到近乎空白、无文字或质量需复核的页，结果区和图片列表会显示状态。通过 **文件 → 重试此页** 可指定相对当前预览的角度，并重新生成这一页的 OCR 文字。其他页以及已有的错题摘录保持原样。

## 摄像头与手机

- 点 **摄像头拍照**，从设备下拉框选择内置或 USB 摄像头，按 **拍照 → 加入工作稿**。也可先重拍。加入后回到取景，可继续拍下一页。取景失败时，检查 Windows 的桌面应用相机权限、设备连接和是否有其他软件正在占用。
- 点 **手机拍照**，手机和电脑连接同一个可信 Wi-Fi，再用手机扫码。拍完确认使用照片，或从相册选图，网页会自动发送。手机显示「照片已加入电脑工作稿第 N 页」后，可在主窗口点 **查看手机照片**，或从页面下拉框切到对应页。处理较慢时，电脑端配对窗口会显示等待导入的进度。支持 JPG、PNG 和 HEIC，每张最多 24 MiB、3200 万像素。
- 配对有效期为 15 分钟，刷新二维码或关闭窗口会结束当前配对。手机端通过局域网 HTTP 传输。如果手机打不开链接，确认扫码工具允许在系统浏览器打开局域网 HTTP 地址，并检查路由器是否隔离设备。在自己信任的家庭或办公网络上，可按 Windows 提示允许 Python 在专用网络接收连接。

## 错题集与导出

1. 框住一道题后点 **收录选区**。需要保存整个区块画面时用 **仅收录原图**。框线切过文字块时，可先用 **识别选区**再收录。每次收录保存当时的文字、类别和配图。有新校对时，可移除旧选题并重新收录。
2. 在错题集里可上下调整顺序。双击条目可回到原图。导出前选 **当前识别范围** 或 **错题集**。
3. 从 **全部、仅印刷体、仅手写体** 中选择。单类输出使用已经归入对应类别的文字和已归类的表格或公式。待确认内容可在校对后加入对应类别。全部模式会带上自动检测到的图表和手动标记的原图。
4. PDF 默认 **白底黑字**，正文可选择、搜索和复制，图表使用裁切图。同一段落、题组或表格使用统一字号。可切换成 **照片版** 保留原页外观，照片版的文字层也会按类别筛选。
5. **保存工作稿**可生成 `*.ocrproj` 文件。它包含原图、识别与校对数据及错题集，换目录也可重开。工作稿与 Word、PDF 分开保存。


## 预览和编辑 Word、PDF

- 在右侧点 **Word 预览** 或 **PDF 预览**。显示当前识别范围或错题集的实际排版，沿用提取类别、图表选项和 PDF 样式。可翻页、放大，或点 **保存此版本** 保存生成时的文档。原图、OCR 结果或设置变化后，重新点击按钮生成新的预览。
- 通过右侧下方的 **文档** 菜单选择 **Word 编辑** 或 **PDF 编辑**，可编辑当前输出，也可打开已有文件。**并排**模式在右侧编辑并保留左侧照片。**全屏**模式在独立最大化窗口编辑。可在编辑器顶部切换布局，已改内容随文档保留。右侧标签放不下时，可通过 **文档 → 切换已打开的文档** 切换。
- Word 编辑可以修改正文和表格内的普通文字，插入、替换、调整或删除图片。文档中的复杂域、公式和链接会保留。Word 排版预览使用 LibreOffice，其他软件的实际换行会随字号和字体环境变化。
- PDF 编辑窗口可排序、旋转、裁剪、删页、追加其他 PDF。拖框后可以高亮或写批注，误操作可用 **撤销**。每次保存选择另存副本。
- 在 PDF 编辑窗口点 **选页送入 OCR**，页码可填 1、1-3 或 1,3-5。随后回主窗口识别、校对并导出。对于扫描页，这会生成新的可搜索文档。
- 第二阶段保存的工作稿可继续打开。校对完成后选 **白底黑字** 导出 PDF，修订过的文字会显示在页面正文里。

## AI 联网辅助

1. 打开 **编辑 → AI 联网辅助 → AI 联网辅助设置**，填写 OpenAI 兼容 API 地址、模型和密钥，然后勾选启用。若服务文档写的是 `/v1/chat/completions`，可填写完整地址或到 `/v1` 为止。密钥保存在 Windows 凭据管理器。使用本机模型时可填写环回 HTTP 地址。
2. 在右侧选中要校对的文字块，或在左侧框出区域，再点 **AI 校对或结构建议**。有活动框选时，以框内内容为发送范围。发送前会显示文字、服务地址以及选区截图选项。发送截图需要支持图像输入的模型。
3. 逐条对比原文与建议，选中后应用。选区可以请求补录、公式和表格建议，生成的内容可先手工修改。应用后可从 **编辑 → AI 联网辅助** 撤销上次 AI 修改，只要该页未被继续修改。

AI 联网辅助默认关闭，设置和打开工作稿时都不会发出请求。本地识别、文档编辑、预览和导出照常可用。真实服务商的接口和视觉模型支持情况请以选用服务为准。

## 给外部 AI Agent 使用

从 **帮助 → 外部 AI Agent 调用说明** 打开软件内的指南，也可以直接读取 [外部 AI 调用说明](外部AI调用说明.md)。Agent 可运行 `ocr-cli.bat recognize` 取得结构化 JSON 和工作稿，通过 `inspect`、`edit`、`export` 读取、校对和导出已有结果。

双栏教材页在校对窗口与导出中按栏阅读。需要修正自动图表时，在左侧框住图表，在 **编辑** 菜单选 **排除框中的自动图表**。要保留拆开的局部，可分别框选并用 **保留原图区域**。恢复操作在同一菜单。要关联图注，先框住图表，再在 **原图校对** 选中一条文字，通过 **校对操作** 绑定或清除关联。Agent 可用 `figures` 将这些图表和公式截图单独导出为 PNG，并读取对应图注。

识别后双击 **原图校对** 中的 **结构待确认**，可对照原图校对公式或表格。也可在左侧自己框选，用 **表格或公式** 调出校对框，无框表格可尝试用这一入口。确认后的公式和表格在 Word 中可编辑，白底 PDF 会按公式结构和表格网格排版。原图中的复杂图形或残缺公式可继续用截图保留。

表格支持 `|` 或 Tab 分列、`^` 与上一行合并。需要表头时，在第一行单独填写 `[表头]`，从下一行输入表格。包含公式的正文可选 **正文与行内公式**，例如 `求证：$x^{2}>0$`。表格单元格也支持用 `$…$` 标记带数学符号的公式。

### A4 讲义和版面检查

在 **展开工具 → 识别与导出** 将文档排版切到 **A4 讲义**。导出范围可选当前页、全部已识别页或错题集，封面与目录可分别开启。Word 使用可导航标题和可编辑对象，白底 PDF 使用同一份讲义内容。在版面预览里点 **版面检查**，或从 **文档 → 最近的版面检查** 打开结果，双击有来源的项目可跳回原图。

A4 目录收录可判定的标题和指定的小节名。可从右侧 **文档 → 设置本页讲义标题** 覆盖自动标题，留空恢复自动判断。选择仅印刷体或仅手写体后，如大量文字被筛除，预览和导出会提示排除行数，详细数据见版面检查。

确认 **正文与行内公式** 后，讲义会在可确定来源的原段中合并相邻正文，Word 公式仍可编辑。难以确定位置的公式按已确认的对象边界保留，可以在原图校对中调整。目录页码从正文第 1 页计算，封面和目录没有正文页码。Word 可更新目录页码域，PDF 目录使用此次生成的实际页码。

在 **原图校对** 双击已确认或待确认的表格，或者框住原图后打开 **编辑 → 逐格编辑选区表格**。可增减行列、设置首行表头和向上合并，格内用 `$…$` 标出公式。选中单元格后，在上方原图框住一小块并点 **放入原图截图**，即可在该格保留原来的图形。图注可以关联到手动保留图、自动图表或已确认的原生表格。

校对筛选可分别查看低置信文字、待核对公式、待核对表格、未关联图注和版面异常。版面异常来自最近的 A4 讲义检查，重新导出后更新。在版面检查窗口可保存 JSON 裁切清单，列出原图位置、资产 ID 和由原生表格替换的候选区域。

还可以选择 **贴近原图** 或 **照片版**。需要按 Word 文件的排版来生成 PDF 时，可在装有 LibreOffice 的环境选择 **Word 同版 PDF**。A4 讲义的 Word 预览在缺少 LibreOffice 时会显示标明来源的内置 PDF 示意，保存仍生成可编辑 Word。

### 批量识别与校对

用 **文件 → 导入图片文件夹** 按自然排序追加照片。批量处理菜单可继续未完成页、重试失败页、停止或恢复任务。停止会等待正在识别的这一页完成。恢复记录写入本机，工作稿保存后清理对应记录。「一键整理为 A4 讲义」复用已识别内容，补识待处理页后打开预览。

### 多张图片合并导出

顺序合并时，在 **展开工具 → 识别与导出 → 导出范围** 选 **全部已识别页**，再点 **导出 Word** 或 **导出 PDF**。每次导出生成一个文档。

需要挑页或改顺序时，从右侧 **文档 → 自选导出页面** 打开列表，勾选所需图片，用上移、下移安排顺序后确认。预览、编辑副本和导出使用这份顺序。保存工作稿后可再次打开这份选择。文字版按所选图片已识别的范围导出，尚未识别的所选页可单独批量识别。照片版可以直接合并整张原图。

右侧可筛选低置信文字和待确认结构。「校对操作」可调整角色、合并或拆分文字、移动讲义阅读顺序，并撤销本页最近的校对。展开工具可保存导出偏好，并在照片 PDF 中选择 150 DPI 分享版。

开发记录与验收结果见 [开发日志](开发日志.md)。阶段目标见 [开发方案](开发方案.md)、[第二大阶段开发方案](第二大阶段开发方案.md) 和 [第三大阶段开发方案](第三大阶段开发方案.md)。

用 `offline.py install` 准备 Windows x64 Python 3.13 环境及 OCR 模型，然后执行以下命令。可用 `--output` 指定新的发布目录。

```powershell
.\.venv\Scripts\python.exe -m pip install -r .\packaging\requirements-build.txt
.\.venv\Scripts\python.exe .\packaging\build_release.py
```
